# Changelog

## 1.0.0 - 2026-11-22

### Added

- **Manage Docker Sandboxes in Orca.** View local sandboxes and their status, create one with Claude Code or Codex, and stop it without deleting its files.
- **Choose how your project is shared.** Start without sharing a host folder, create a writable clone of a local Git repository, or explicitly confirm a direct mount that lets the sandbox write to your host checkout.
- **Connect over SSH.** View the connection settings and test OpenSSH from the panel before adding the target in Orca. Multiple worktrees can share the same sandbox.
- **Use the panel in English or French.** Controls, help, and error messages follow Orca's interface language, with English as the fallback.
- **Get started on Linux.** The [README](README.md) includes installation and SSH setup instructions, troubleshooting, and a screenshot of the panel in Orca Desktop.
